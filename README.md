# SIGNAL – Digital Marketing Services Website

A modern, responsive, and conversion-focused digital marketing services website developed as part of a Web & Product Development Internship assignment.

## Overview

SIGNAL is a digital marketing agency website designed to help businesses improve their online presence, generate qualified leads, and drive measurable growth through data-driven marketing strategies.

The project focuses on modern UI/UX principles, responsive design, lead generation, and customer engagement while maintaining a professional business-oriented appearance.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern hero section with call-to-action buttons
- Pain points and business solution sections
- Services carousel/slider
- Pricing plans with comparison table
- Results and case studies section
- Revenue impact simulator
- Client testimonials
- Contact and inquiry form with validation
- Animated statistics and counters
- Social proof notifications
- Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
